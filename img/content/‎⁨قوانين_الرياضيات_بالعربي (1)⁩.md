# قوانين الرياضيات - الصف الثاني عشر (بالرموز العربية)

**ملاحظة:** الرموز المثلثية بالعربي هي: جا = جيب (sin) , جتا = جيب التمام (cos) , ظا = ظل (tan) , قتا = قاطع التمام (csc) , قا = قاطع (sec) , ظتا = ظل التمام (cot)

---

## 1. النهايات (النهايات)

- نهاية مجموع/فرق: نها[د(س) ± ه(س)] = نها د(س) ± نها ه(س)
- نهاية حاصل ضرب: نها[د(س)·ه(س)] = نها د(س) · نها ه(س)
- نهاية القسمة: نها[د(س)/ه(س)] = نها د(س) / نها ه(س) ، بشرط نها ه(س) ≠ صفر
- نهاية القوة: نها[د(س)]ن = [نها د(س)]ن
- النهاية الشهيرة: نها (س→٠) (جا س)/س = ١
- النهاية الشهيرة: نها (س→٠) (١ - جتا س)/س = ٠
- النهاية الشهيرة: نها (س→٠) (ظا س)/س = ١
- النهاية الشهيرة: نها (س→∞) (١ + ١/س)ˢ = هـ (عدد أويلر)
- نهاية كثيرة الحدود عند اللانهاية: تُحدَّد بحد الرتبة الأعلى فقط
- الاتصال عند نقطة: د متصلة عند س = أ إذا كان نها(س→أ) د(س) = د(أ)

---

## 2. الاشتقاق

### القواعد الأساسية
- مشتقة الثابت = صفر
- مشتقة (سⁿ) = ن·سⁿ⁻¹
- مشتقة (ثابت × د(س)) = ثابت × د'(س)
- مشتقة (د ± ه) = د' ± ه'
- قاعدة الضرب: (د·ه)' = د'ه + ده'
- قاعدة القسمة: (د/ه)' = (د'ه - ده')/ه²
- قاعدة السلسلة: (د(ه(س)))' = د'(ه(س))·ه'(س)

### مشتقات الدوال الأساسية
- (جا س)' = جتا س
- (جتا س)' = -جا س
- (ظا س)' = قا²س
- (ظتا س)' = -قتا²س
- (قا س)' = قا س·ظا س
- (قتا س)' = -قتا س·ظتا س
- (هـˢ)' = هـˢ
- (أˢ)' = أˢ·لو ط أ
- (لو ط س)' = ١/س
- (لوﺃس)' = ١/(س·لو ط أ)
- (√س)' = ١/(٢√س)

### تطبيقات المشتقة
- ميل المماس عند نقطة: م = د'(أ)
- معادلة المماس: ص - ص١ = د'(أ)(س - س١)
- معادلة العمودي على المماس: ص - ص١ = -١/د'(أ) × (س - س١)
- الدالة متزايدة عند س=أ إذا د'(أ) > صفر، متناقصة إذا د'(أ) < صفر
- النقاط الحرجة: عند د'(س) = صفر أو د'(س) غير معرّفة
- اختبار المشتقة الثانية: إذا د''(أ) > صفر فالنقطة صغرى، وإذا د''(أ) < صفر فالنقطة عظمى
- نقطة الانقلاب: عند د''(س) = صفر مع تغيّر التقعر
- السرعة: ع(ن) = ف'(ن) [مشتقة الإزاحة]
- التسارع: تسـ(ن) = ع'(ن) = ف''(ن)

## 3. التكامل

### التكامل غير المحدود
- ∫سⁿ د س = سⁿ⁺¹/(ن+١) + ك ، (ن ≠ -١)
- ∫(١/س) د س = لو ط|س| + ك
- ∫هـˢ د س = هـˢ + ك
- ∫أˢ د س = أˢ/لو ط أ + ك
- ∫جا س د س = -جتا س + ك
- ∫جتا س د س = جا س + ك
- ∫قا²س د س = ظا س + ك
- ∫قتا²س د س = -ظتا س + ك
- ∫قا س·ظا س د س = قا س + ك
- ∫قتا س·ظتا س د س = -قتا س + ك

### طرق التكامل
- التكامل بالتعويض
- التكامل بالأجزاء: ∫ت د ث = ت ث - ∫ث د ت

### التكامل المحدود
- ∫[من أ إلى ب] د(س) د س = ف(ب) - ف(أ)
- المساحة بين منحنيين: م = ∫[من أ إلى ب] [د(س) - ه(س)] د س
- حجم الدوران حول محور س: ح = ط∫[من أ إلى ب] [د(س)]² د س
- خاصية: ∫[من أ إلى أ] د(س) د س = صفر
- خاصية: ∫[من أ إلى ب] د(س) د س = -∫[من ب إلى أ] د(س) د س

## 4. حساب المثلثات

### المتطابقات الأساسية
- جا²هـ + جتا²هـ = ١
- ١ + ظا²هـ = قا²هـ
- ١ + ظتا²هـ = قتا²هـ
- ظا هـ = جا هـ / جتا هـ
- ظتا هـ = جتا هـ / جا هـ
- قا هـ = ١/جتا هـ
- قتا هـ = ١/جا هـ

### قوانين الجمع والفرق
- جا(أ ± ب) = جا أ جتا ب ± جتا أ جا ب
- جتا(أ ± ب) = جتا أ جتا ب ∓ جا أ جا ب
- ظا(أ ± ب) = (ظا أ ± ظا ب)/(١ ∓ ظا أ ظا ب)

### الزاوية المضاعفة
- جا ٢هـ = ٢ جا هـ جتا هـ
- جتا ٢هـ = جتا²هـ - جا²هـ = ٢جتا²هـ - ١ = ١ - ٢جا²هـ
- ظا ٢هـ = ٢ظا هـ/(١ - ظا²هـ)

### نصف الزاوية
- جا(هـ/٢) = ±√[(١-جتا هـ)/٢]
- جتا(هـ/٢) = ±√[(١+جتا هـ)/٢]
- ظا(هـ/٢) = ±√[(١-جتا هـ)/(١+جتا هـ)]

### قوانين المثلث العام
- قانون الجيب: جـ/جا أ = ص/جا ب = ع/جا جـ = ٢نق (نق = نصف قطر الدائرة المحيطة)
- قانون جيب التمام: جـ² = ص² + ع² - ٢ص ع·جتا أ
- مساحة المثلث: م = ½ ص ع·جا جـ
- مساحة المثلث (قانون هيرون): م = √[ح(ح-جـ)(ح-ص)(ح-ع)] ، حيث ح = (جـ+ص+ع)/٢

## 5. المتتاليات والمتسلسلات

### المتتالية الحسابية
- الحد العام: حن = ح١ + (ن-١)د
- مجموع ن حد: مجن = ن/٢ [٢ح١ + (ن-١)د] = ن/٢ (ح١ + حن)

### المتتالية الهندسية
- الحد العام: حن = ح١ · قⁿ⁻¹ (ق = الأساس)
- مجموع ن حد: مجن = ح١(١ - قⁿ)/(١ - ق) ، (ق ≠ ١)
- مجموع متسلسلة هندسية لانهائية: مج∞ = ح١/(١ - ق) ، بشرط │ق│< ١

---

## 6. الأعداد المركبة

- الصورة الجبرية: ع = أ + ب×ت ، حيث ت² = -١
- المقياس: │ع│= √(أ² + ب²)
- المرافق: ع̄ = أ - ب×ت
- الصورة القطبية: ع = نق(جتا هـ + ت·جا هـ)، حيث نق = │ع│، هـ = ظا⁻¹(ب/أ)
- الضرب في الصورة القطبية: ع١·ع٢ = نق١نق٢[جتا(هـ١+هـ٢) + ت·جا(هـ١+هـ٢)]
- القسمة في الصورة القطبية: ع١/ع٢ = (نق١/نق٢)[جتا(هـ١-هـ٢) + ت·جا(هـ١-هـ٢)]
- نظرية ديموافر: عⁿ = نقⁿ(جتا ن هـ + ت·جا ن هـ)

---

## 7. المتجهات

- المتجه في الفراغ: م = (س, ص, ع)
- المقياس: │م│= √(س² + ص² + ع²)
- الضرب القياسي: أ·ب = أ١ب١ + أ٢ب٢ + أ٣ب٣ = │أ││ب│جتا هـ
- الضرب الاتجاهي: │أ×ب│= │أ││ب│جا هـ
- شرط التعامد: أ·ب = صفر
- شرط التوازي: أ×ب = صفر (أو أ = ك ب)
- متجه الوحدة: و = م/│م│

---

## 8. الإحصاء والاحتمالات

### الإحصاء
- الوسط الحسابي: س̄ = مجـ سي/ن
- التباين: ت² = مجـ(سي - س̄)²/ن
- الانحراف المعياري: ت = √[مجـ(سي - س̄)²/ن]
- معامل الاختلاف: م.أ = (ت/س̄) × ١٠٠٪

### الاحتمالات
- احتمال حدث: ت(أ) = عدد النتائج المطلوبة / عدد النتائج الممكنة
- الحدث المتمم: ت(أَ') = ١ - ت(أ)
- احتمال الاتحاد: ت(أ∪ب) = ت(أ) + ت(ب) - ت(أ∩ب)
- الأحداث المنفصلة: ت(أ∪ب) = ت(أ) + ت(ب)
- الاحتمال الشرطي: ت(أ│ب) = ت(أ∩ب)/ت(ب)
- الأحداث المستقلة: ت(أ∩ب) = ت(أ)·ت(ب)
- التوافيق: نتوك = ن!/[ك!(ن-ك)!]
- التباديل: نبك = ن!/(ن-ك)!
- التوقع الرياضي: ت.ر(س) = مجـ[سي·ت(سي)]

## 9. اللوغاريتمات والأسس

- لوﺃ(س ص) = لوﺃس + لوﺃص
- لوﺃ(س/ص) = لوﺃس - لوﺃص
- لوﺃ(سⁿ) = ن·لوﺃس
- لوﺃأ = ١ ، لوﺃ١ = صفر
- تغيير الأساس: لوﺃس = لو ط س/لو ط أ
- أˢ = ص ⟺ س = لوﺃص

## 10. الهندسة التحليلية

- ميل الخط المستقيم: م = (ص٢-ص١)/(س٢-س١)
- معادلة الخط (نقطة وميل): ص - ص١ = م(س - س١)
- المسافة بين نقطتين: م.ن = √[(س٢-س١)² + (ص٢-ص١)²]
- منتصف القطعة: و = ((س١+س٢)/٢ , (ص١+ص٢)/٢)
- معادلة الدائرة: (س-م)² + (ص-ن)² = نق²
- معادلة القطع المكافئ: ص² = ٤ب س
- معادلة القطع الناقص: س²/أ² + ص²/ب² = ١
- معادلة القطع الزائد: س²/أ² - ص²/ب² = ١

## ملاحظة مهمة

الرموز العربية للدوال المثلثية (جا، جتا، ظا) هي المستخدمة تقليديًا في بعض المناهج الخليجية والعربية، لكن كثير من المدارس الحديثة في الخليج تستخدم الرموز اللاتينية (sin, cos, tan) حتى داخل النص العربي. راجع كتابك المدرسي لمعرفة أي رمزين يعتمدهما منهجك بالضبط.
