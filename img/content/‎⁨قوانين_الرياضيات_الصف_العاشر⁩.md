# قوانين الرياضيات - الصف العاشر

## أولاً: الجبر

### 1. الأسس والجذور
$$a^m \times a^n = a^{m+n} \qquad \dfrac{a^m}{a^n} = a^{m-n} \qquad (a^m)^n = a^{m \times n}$$
$$a^0 = 1 \qquad a^{-n} = \dfrac{1}{a^n} \qquad \sqrt[n]{a} = a^{\frac{1}{n}}$$

### 2. التحليل إلى عوامل
- **العامل المشترك**: $ab + ac = a(b+c)$
- **فرق مربعين**: $a^2 - b^2 = (a-b)(a+b)$
- **مربع كامل**: $a^2 \pm 2ab + b^2 = (a \pm b)^2$
- **فرق مكعبين**: $a^3 - b^3 = (a-b)(a^2+ab+b^2)$
- **مجموع مكعبين**: $a^3 + b^3 = (a+b)(a^2-ab+b^2)$

### 3. المعادلات
- **المعادلة الخطية**: $ax + b = 0 \Rightarrow x = -\dfrac{b}{a}$
- **المعادلة التربيعية (القانون العام)**:
$$x = \dfrac{-b \pm \sqrt{b^2-4ac}}{2a}$$
- **المميز**: $\Delta = b^2 - 4ac$
  - إذا $\Delta > 0$: جذران حقيقيان مختلفان
  - إذا $\Delta = 0$: جذر حقيقي واحد (مكرر)
  - إذا $\Delta < 0$: لا يوجد جذر حقيقي

### 4. المتباينات
عند الضرب أو القسمة على عدد سالب، تنعكس علامة المتباينة

## ثانياً: الدوال

### 1. مفهوم الدالة
$$f(x) = y$$
كل قيمة لـ $x$ (المجال) تقابلها قيمة واحدة فقط لـ $y$ (المدى)

### 2. الدالة الخطية
$$f(x) = mx + b$$
- $m$: الميل، $b$: نقطة تقاطع المحور الصادي

### 3. ميل الخط المستقيم
$$m = \dfrac{y_2 - y_1}{x_2 - x_1}$$

### 4. معادلة الخط المستقيم
- الصورة الميلية: $y = mx + b$
- صورة نقطة وميل: $y - y_1 = m(x - x_1)$

### 5. الدالة التربيعية
$$f(x) = ax^2 + bx + c$$
- إحداثيات رأس القطع المكافئ: $x = \dfrac{-b}{2a}$

### 2. نقطة المنتصف

## رابعاً: المثلثات والهندسة

### 1. نظرية فيثاغورس
$$c^2 = a^2 + b^2$$

### 2. النسب المثلثية (في المثلث القائم الزاوية)
$$\sin\theta = \dfrac{\text{المقابل}}{\text{الوتر}} \qquad \cos\theta = \dfrac{\text{المجاور}}{\text{الوتر}} \qquad \tan\theta = \dfrac{\text{المقابل}}{\text{المجاور}}$$

### 3. مجموع زوايا المثلث
$$\text{مجموع زوايا المثلث} = 180°$$

### 4. تشابه وتطابق المثلثات
- تطابق: تساوي جميع الأضلاع والزوايا المتناظرة
- تشابه: تناسب الأضلاع المتناظرة وتساوي الزوايا المتناظرة
