# 📘 الفصل الدراسي الأول

## أولاً: الأعداد الحقيقية والأسس

### 1. الأعداد الحقيقية
- الأعداد النسبية: يمكن كتابتها على صورة $\dfrac{a}{b}$ حيث $b\neq0$
- الأعداد غير النسبية: لا يمكن كتابتها على صورة كسر (مثل $\sqrt2,\ \pi$)
- الجذر التربيعي للعدد $a$: العدد الذي إذا ضُرب في نفسه يعطي $a$

### 2. الأسس

| القانون | الصيغة |
|---|---|
| ضرب الأسس | $a^m \times a^n = a^{m+n}$ |
| قسمة الأسس | $\dfrac{a^m}{a^n} = a^{m-n}$ |
| أس الأس | $(a^m)^n = a^{mn}$ |
| أس الضرب | $(ab)^n = a^n b^n$ |
| أس الكسر | $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$ |
| الأس صفر | $a^0=1\quad(a\neq0)$ |
| الأس السالب | $a^{-n}=\dfrac{1}{a^n}$ |

### 3. الجذور
$$\sqrt{a}\times\sqrt{b}=\sqrt{ab}\qquad \dfrac{\sqrt{a}}{\sqrt{b}}=\sqrt{\dfrac{a}{b}}\qquad (\sqrt{a})^2=a$$

### 4. الصورة العلمية (القياسية)
$$a\times10^n \quad \text{حيث } 1\le a<10$$

## ثانياً: الجبر

### 1. الحدود الجبرية والعمليات عليها
- جمع/طرح الحدود المتشابهة: تُجمع معاملاتها فقط
- ضرب حد بحد: $a^m\times a^n=a^{m+n}$
- ضرب حد في مقدار جبري: توزيع الضرب على كل حد (خاصية التوزيع)
$$a(b+c)=ab+ac$$

### 2. حاصل ضرب مقدارين جبريين
- $(a+b)(c+d)=ac+ad+bc+bd$
- $(a+b)^2=a^2+2ab+b^2$
- $(a-b)^2=a^2-2ab+b^2$
- $(a+b)(a-b)=a^2-b^2$

### 3. التحليل (العوملة)
- العامل المشترك الأكبر: $ab+ac=a(b+c)$
- فرق مربعين: $a^2-b^2=(a+b)(a-b)$
- المربع الكامل: $a^2+2ab+b^2=(a+b)^2$
- التحليل بالتجميع: $ab+ac+db+dc=a(b+c)+d(b+c)=(a+d)(b+c)$

### 4. المعادلات الخطية
- حل المعادلة من الدرجة الأولى بمجهول واحد: عزل المتغير بإجراء نفس العملية على الطرفين
- حل نظام معادلتين خطيتين بمتغيرين:
  - **طريقة الحذف (الجمع أو الطرح)**
  - **طريقة التعويض**
  - **الحل بيانياً**: نقطة تقاطع الخطين

### 5. المتباينات
- عند الضرب أو القسمة على عدد سالب تنعكس إشارة المتباينة
$$a<b \Rightarrow -a>-b$$

## ثالثاً: الهندسة

### 1. المضلعات
| الخاصية | القانون |
|---|---|
| مجموع الزوايا الداخلية لمضلع $n$ ضلع | $(n-2)\times180°$ |
| قياس الزاوية الداخلية لمضلع منتظم | $\dfrac{(n-2)\times180°}{n}$ |
| مجموع الزوايا الخارجية لأي مضلع محدب | $360°$ |

### 2. متوازي الأضلاع وأنواعه
- في متوازي الأضلاع: كل ضلعين متقابلين متوازيان ومتطابقان
- الأقطار تنصف بعضها
- **المستطيل**: الأقطار متطابقة
- **المعين**: الأقطار متعامدة وتنصف الزوايا
- **المربع**: يجمع خصائص المستطيل والمعين

### 3. المثلثات
- مجموع زوايا المثلث $=180°$
- **نظرية فيثاغورس** (للمثلث القائم):
$$c^2=a^2+b^2$$
- متباينة المثلث: مجموع طول أي ضلعين أكبر من الضلع الثالث

### 4. التطابق والتشابه
- حالات تطابق المثلثات: (ض.ز.ض)، (ز.ض.ز)، (ض.ض.ض)، (ض.ز.ز)
- في المثلثات المتشابهة: الزوايا متطابقة والأضلاع المتناظرة متناسبة

# 📗 الفصل الدراسي الثاني

## أولاً: الجبر

### 1. الاقتران الخطي (الدالة الخطية)

**الميل**
$$m=\dfrac{y_2-y_1}{x_2-x_1}$$

**معادلة الخط المستقيم**
- الصورة الميلية: $y=mx+b$
- صورة نقطة وميل: $y-y_1=m(x-x_1)$

**العلاقة بين الخطوط**
- متوازيان: $m_1=m_2$
- متعامدان: $m_1\times m_2=-1$

### 2. جمع وطرح وضرب كثيرات الحدود
- ترتيب كثيرة الحدود تنازلياً حسب الأس
- الضرب: توزيع كل حد من الأول على كل حد من الثاني

### 3. القسمة على مقدار جبري
$$\dfrac{a+b}{c}=\dfrac{a}{c}+\dfrac{b}{c}$$

## ثانياً: الهندسة

### 1. المساحات

| الشكل | القانون |
|---|---|
| المربع | $M=a^2$ |
| المستطيل | $M=a\times b$ |
| متوازي الأضلاع | $M=\text{القاعدة}\times\text{الارتفاع}$ |
| المثلث | $M=\dfrac{1}{2}\times\text{القاعدة}\times\text{الارتفاع}$ |
| شبه المنحرف | $M=\dfrac{1}{2}(a+b)\times h$ |
| المعين | $M=\dfrac{1}{2}\times d_1\times d_2$ |
| الدائرة | $M=\pi r^2$ |
| محيط الدائرة | $L=2\pi r$ |

### 2. المجسمات (الحجوم والمساحات)

| المجسم | الحجم | المساحة الكلية |
|---|---|---|
| المكعب | $V=a^3$ | $M=6a^2$ |
| متوازي المستطيلات | $V=l\times w\times h$ | $M=2(lw+lh+wh)$ |
| المنشور القائم | $V=\text{مساحة القاعدة}\times h$ | $M=2\times\text{مساحة القاعدة}+\text{المساحة الجانبية}$ |
| الأسطوانة | $V=\pi r^2h$ | $M=2\pi rh+2\pi r^2$ |

### 3. الإحداثيات والتحويلات الهندسية
- **الانسحاب (الإزاحة)**: تحريك الشكل دون تغيير حجمه أو اتجاهه
- **الانعكاس**: قلب الشكل حول محور (مرآة)
- **الدوران**: تدوير الشكل حول نقطة بزاوية معينة
- **التكبير/التصغير**: تغيير الحجم بنسبة معينة مع بقاء الشكل متشابهاً للأصلي

### 4. المسافة بين نقطتين ونقطة المنتصف
$$d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$$
$$M=\left(\dfrac{x_1+x_2}{2},\dfrac{y_1+y_2}{2}\right)$$

## ثالثاً: الاحتمالات والإحصاء

### 1. الاحتمالات
$$P(A)=\dfrac{\text{عدد النتائج المطلوبة}}{\text{عدد النتائج الممكنة}}$$
- احتمال الحدث المتمم: $P(A')=1-P(A)$
- احتمال حدثين مستقلين: $P(A\text{ و }B)=P(A)\times P(B)$

### 2. الإحصاء

| المفهوم | القانون |
|---|---|
| الوسط الحسابي | $\bar{x}=\dfrac{\sum x}{n}$ |
| الوسيط | القيمة الوسطى بعد الترتيب التصاعدي |
| المنوال | القيمة الأكثر تكراراً |
| المدى | أكبر قيمة $-$ أصغر قيمة |
